Place individually sourced block textures in this directory (for example
`stone.png`, `dirt.png`, `grass_top.png`, `grass_side.png`, `oak_log.png`, and
`oak_leaves.png`). Optional Frontier textures include `jungle_log.png`,
`jungle_leaves.png`, `red_sand.png`, `red_sandstone.png`, and
`magenta_crystal.png`. Missing or unreadable files use procedural pixel-texture
fallbacks. No game assets are included.
